# User Profiles Management App

A modern, responsive React application for managing user profiles with complete CRUD functionality.

## 🚀 Features

- **User List View**: Display all users in a clean, organized table
- **Add Users**: Quick user creation with modal form
- **User Profiles**: Detailed profile pages with tabbed interface
  - Basic Info
  - Education & Skills
  - Work Experience
- **Edit Functionality**: Update user information inline
- **Delete Users**: Remove users with confirmation dialog
- **Responsive Design**: Works seamlessly on all devices

## 🛠️ Tech Stack

- **React** (v18.2.0) - Frontend framework
- **Tailwind CSS** (v3.3.5) - Utility-first CSS framework
- **React Router** (v6.20.0) - Client-side routing
- **JavaScript ES6+** - Modern JavaScript features
